To stream live telemetry from physical transducers wired to a Raspberry Pi into the monitoring system, send an HTTP POST request to /api/inject: 

POST /api/inject HTTP/1.1
Content-Type: application/json

{
    "Voltage_RMS": 415.2,
    "Irms": 18.4,
    "Power_Factor": 0.91,
    "Phase_Angle": 24.5,
    "I_THD": 3.2,
    "Vibration_X": 0.12,
    "Vibration_Y": 0.08,
    "Vibration_Z": 9.81,
    "RMS_Vibration": 2.84,
    "Peak_Acceleration": 4.12,
    "Dominant_Frequency": 49.8,
    "Spectral_Energy": 145.2,
    "Operating_Hours": 1250.0
}

The backend receives telemetry, validates features in training order, executes XGBoost condition inference, and broadcasts live telemetry packets to Laptop 1 & Laptop 2 displays via WebSocket.
